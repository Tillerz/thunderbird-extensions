# Thunderbird Themes

Dark themes for Mozilla Thunderbird. Each theme consists of a `manifest.json` theme (main UI colors) plus optional `userChrome.css` / `userContent.css` files for a finer-tuned look.

| Theme | Description | Palette | Install guide |
|-------|-------------|---------|---------------|
| [Discord Dark](discord-dark/) | Discord-inspired dark theme | #313338 main, #5865f2 accent | [discord-dark/README.md](discord-dark/README.md) |
| [VS Code Dark](vscode-dark/) | VS Code Dark Modern-inspired theme | #1f1f1f editor, #0078d4 accent | [vscode-dark/README.md](vscode-dark/README.md) |

## Quick start

1. Open the folder of the theme you want and follow its README.
2. Install the theme via **Add-ons and Themes** > gear icon > **Install Add-on From File...** (prebuilt `.xpi` files are included in each folder).
3. Optionally copy `userChrome.css` and `userContent.css` into your profile's `chrome` folder and enable `toolkit.legacyUserProfileCustomizations.stylesheets`.
